# Артефакты решения

Здесь хранится рабочая документация по развитию Loopkeeper: актуальная постановка, архитектурные решения, API-контракты, планы и результаты проверок.

## Актуальные документы

- [`MVP-PLAN.md`](MVP-PLAN.md) — согласуемый scope всего MVP, правила доступа и последовательность реализации.
- [`DECISIONS.md`](DECISIONS.md) — журнал принятых решений и открытые вопросы.

## Архив

- [`archive/PLAN.original.md`](archive/PLAN.original.md) — исходная постановка и первоначальный план.
- [`archive/TODO.auth.original.md`](archive/TODO.auth.original.md) — исходный backlog улучшений аутентификации.

Архивные документы не определяют текущий scope: при конфликте приоритет имеют документы из раздела «Актуальные».

## Правила

- Новые артефакты оформляются в Markdown и получают понятное имя.
- В документацию не добавляются секреты, production-дампы и персональные данные.
- После принятия решения обновляется соответствующий актуальный документ, а не архив.
